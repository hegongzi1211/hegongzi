# 火山引擎语音克隆接入（学员可选配音后端）

本模板原本只支持**本机 Voicebox.app** 配音（`provider: voicebox_local`）。本指南新增一个**云端可替换后端**：火山引擎（Volcano Engine）「声音复刻 + 大模型语音合成」。

适合这几种学员：

- 不想在自己机器装 Voicebox、也不想为配音单独准备 GPU 的；
- 想跨设备/团队协作、用同一套云端音色出片的；
- 想要更稳定的长文本批量合成、不依赖本机服务的。

> ⚠️ 火山引擎是**付费云服务**（有免费额度，但超出即计费，且后付费音色「首次正式合成即固定」）。它和 Voicebox 是**二选一**关系，模板靠 `audio-pipeline.json` 的 `provider` 字段切换，已有 Voicebox 流程完全不受影响。

---

## 一、为什么接火山引擎（对比 Voicebox 本地方案）

| 维度 | Voicebox 本机（`voicebox_local`） | 火山引擎云端（`volcengine`） |
|---|---|---|
| 依赖 | 必须装 Voicebox.app + 本地服务（127.0.0.1:17493），吃 GPU/内存 | 只需 API Key + 联网，无本机重依赖 |
| 音色来源 | 本机克隆你自己的声音（1 条样本） | 上传样本到云端「声音复刻」训练，得到 `speaker_id` |
| 跨设备 | 每台机器各自克隆 | 一个 `speaker_id` 到处可用 |
| 成本 | 一次性本地部署，无调用费 | 免费额度 + 按字符/音色槽位计费 |
| 离线 | 可离线 | 必须联网 |
| 合规 | 声音留在本地 | 音频样本与合成走云端（注意数据出境） |

**结论**：手头有 Mac + Voicebox 的学员继续用 `voicebox_local`；想要轻量、跨设备、不折腾本机的，切到 `volcengine`。

---

## 二、前置准备（一次性）

1. 注册并登录 [火山引擎控制台](https://console.volcengine.com/)。
2. 进入 **豆包语音 / 语音合成** 控制台（新版：`console.volcengine.com/speech/new`），在「开通管理」里开通：
   - **声音复刻模型 2.0**（复刻音色必须）；
   - 若用后付费音色，还需单独开通「后付费音色服务」。
3. 在「API Key 管理」新增一个 **API Key**，复制保存（这就是 `X-Api-Key`）。
4. （预付费音色）在「音色库」创建一个音色槽位，拿到 `speaker_id`；后付费音色则训练时用 `--custom-speaker-id` 自定义即可。

> 免费额度以控制台为准：通常赠送一定次数训练 + 一定字符数的试听/合成。具体见控制台与[计费说明](https://www.volcengine.com/docs/6561/1359370)。

## 三、核心概念（先看懂再动手）

- **声音复刻（Voice Clone）**：上传一段你念的人声样本 → 云端训练 → 得到一个可复用的 `speaker_id`（形如 `icl_xxxx` 或 `S_xxxx`）。训练是**异步**的，提交后要轮询状态。
- **合成（TTS）**：用这个 `speaker_id` 当发音人，把任意文本合成成你的声音。本模板用 **V3 单向流式（SSE）** 接口，Header 用 `X-Api-Resource-Id: seed-icl-2.0` 选「声音复刻 2.0」模型。
- **关键限制（务必读）**：
  - 训练最多 **15 次**（预付费/免费音色），超过报错；
  - **后付费音色**：首次正式合成即视为「转正」并收取音色槽位费，**一旦合成该音色即固定、不可再训练**；试听音色若 **7 天**未正式调用会被系统删除；
  - 样本文件 **< 10MB**，建议 10~60 秒、无背景音、无噪音的干净人声。

## 四、一步：克隆你的声音（训练）

准备一段干净人声样本（如 `my-voice.wav`），运行模板自带工具：

```bash
cd "$REMOTION_TEMPLATE_DIR"

# 预付费音色：speaker_id 用控制台音色库创建的 ID
python3 scripts/ve_voice_clone.py train \
  --sample my-voice.wav \
  --speaker-id icl_myvoice \
  --text "这是一段用于复刻的参考文本，建议和样本内容一致。" \
  --demo-text "你好，这是我的声音复刻测试。"

# 或后付费音色：用自定义 ID（首次合成即转正收费）
python3 scripts/ve_voice_clone.py train \
  --sample my-voice.wav \
  --custom-speaker-id custom_zh_myvoice \
  --demo-text "你好，这是我的声音复刻测试。"
```

脚本会输出 `speaker_id` 和 `status`。训练是异步的，状态 `1=Training` 时还没好。

API Key 来源优先级：`--api-key` > 环境变量 `VOLCENGINE_API_KEY` > `audio-pipeline.json` 的 `api_key` 字段。

---

## 五、二步：查询训练状态

```bash
python3 scripts/ve_voice_clone.py query --speaker-id icl_myvoice
# 后付费：python3 scripts/ve_voice_clone.py query --custom-speaker-id custom_zh_myvoice
```

直到 `status=2(Success)` 或 `4(Active)` 即可用于合成。**后付费音色请先试听 `demo_audio` 确认效果满意**，再走下一步正式合成（首次正式合成会固定并计费）。

---

## 六、三步：把复刻音色接进音频管线

打开模板根目录 `audio-pipeline.json`，**把 provider 从 `voicebox_local` 改成 `volcengine`**，并填入火山引擎字段。最省事的办法是直接复制示例：

```bash
cp skill/references/student-audio-pipeline-volcengine.example.json audio-pipeline.json
```

然后按自己情况改这 4 个字段即可：

| 字段 | 含义 | 必填 |
|---|---|---|
| `api_key` | 火山引擎 API Key（`X-Api-Key`） | ✅ |
| `speaker_id` | 复刻得到的 `icl_/S_` 开头音色 ID | ✅ |
| `resource_id` | 固定 `seed-icl-2.0`（声音复刻 2.0） | ✅ |
| `language` / `speed` / `volume` / `pitch` | 语种与语速/音量/音调微调 | 可选 |

`outro_voice.text` 仍是你的片尾口播（如 `我是小明，关注我，学习更多 AI 知识。`），`outro_voice.speaker_id` 填同一个复刻音色 ID。

改完后，**后续流程全自动、无需改任何命令**：`build_video.py` 检测到 `provider=volcengine` 会自动改调 `ve_generate.py` 合成旁白，`make:render` 照常渲染。

## 七、手动生成片尾人声（与 Voicebox 路径一致）

```bash
echo "我是小明，关注我，学习更多 AI 知识。" > outro.txt
python3 scripts/ve_generate.py --text-file outro.txt --output public/generated/outro-voice.wav
```

`ve_generate.py` 与 `voicebox_generate.py` 命令行完全一致（`--text-file` / `--output`），所以 `build_video.py` 能无缝切换。

## 八、与 Voicebox 方案的切换速查

| 想用 | `audio-pipeline.json` 的 `provider` | 配套动作 |
|---|---|---|
| 本机 Voicebox | `voicebox_local` | 装 Voicebox.app，填 `profile_id`/`profile_name`/`service_url` |
| 火山引擎云端 | `volcengine` | 填 `api_key`/`speaker_id`，先 `ve_voice_clone.py train`+`query` 拿到 speaker_id |

两套配置结构不同，**不要混填字段**。`provider` 的值决定模板读取哪一组字段，并在 `build_video.py` / `build_per_scene.py` / 校验脚本里统一放行。

## 九、成本与合规提醒

- **先试听、后转正**：后付费音色首次正式合成即收费并固定，务必先 `query` 试听 `demo_audio`。
- **训练次数**：免费/预付费音色共 15 次训练上限，慎重上传样本。
- **7 天规则**：后付费试听音色 7 天未正式调用会被删除，需重新训练。
- **数据出境**：音频样本与合成文本会发送到火山引擎云端，涉及敏感内容请自行评估合规风险。
- **不绑定任何本机资源**：与 Voicebox 方案一样，本集成不绑定何公子任何音色/账号。

## 十、常见问题

**Q：合成报错 code 非 1000？**
A：看 `message`。常见：`speaker_id` 填错/未训练完成（status 非 2/4）、`api_key` 无效、账户额度耗尽、文本超长。先用 `ve_voice_clone.py query` 确认 status 就绪。

**Q：训练返回 status=3(Failed)？**
A：样本质量问题（噪音大、时长过短/过长、文本与音频不符导致 WER 过大）。换更干净的 10~60s 人声，必要时加 `--denoise`，或减小 `--text` 与样本的偏差。

**Q：返回「音频超过 10MB」？**
A：样本必须小于 10MB。用 ffmpeg 转成较低码率 mp3 或裁剪长度即可。

**Q：能离线用吗？**
A：不能。火山引擎是云端服务，必须联网；需要离线请用 `voicebox_local`。

**Q：Whisper 还必需吗？**
A：必需。`ve_generate.py` 只负责合成旁白音频，`build_video.py` 仍要用 `whisper-cli` 做字幕时间轴对齐。Whisper 与配音后端无关，两个 provider 都要装。

**Q：能用声音复刻 1.0 吗？**
A：可以，把 `resource_id` 改成 `seed-icl-1.0`（或 `seed-icl-1.0-concurr`）。本模板默认 2.0 效果更好。
