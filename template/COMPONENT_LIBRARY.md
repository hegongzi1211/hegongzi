# 【你的名字】终稿视频版式组件库

这套模板采用“固定品牌系统 + 内容自适应版式”，不是把所有文章塞进同一张页面。

## 内容生产前置流程

`文章/文字/图片 → 提取事实与素材 → 重写爆款口播脚本 → 版式选型 → 连续配音 → 字幕与画面同步`

正式制作必须先按 `SCRIPT_TEMPLATE.md` 创建 `script.md`。构建脚本会先执行口播结构检查；缺少 Hook、留存承诺、痛点、悬念、价值段、记忆句或 CTA 时，不允许进入配音阶段。

## 固定不变

- 1080 × 1440、30 fps、科技感深色背景。
- 顶部编号、霓虹进度线、主标题框、底部微型补充信息和字幕安全区。
- 封面约 1.5 秒，封面不显示字幕。
- 当前Remotion模板锁定本机Voicebox正文档案 `你的Voicebox档案ID`（`【你的名字】终稿原声-Remotion专用`），直接取样自 `终稿-音频.wav`；使用Qwen3-TTS 0.6B。
- `src/template/scenes/LockedOutro.tsx` 为锁定片尾，直接叠加在统一科技背景中，不允许正文生成流程覆盖。

## 正文版式

| 类型 | 用途 | 建议信息量 |
|---|---|---|
| `skill_detail` | 单工具、单概念、单方法的能力清单 | 左侧核心聚焦 + 右侧解释清单，2—4 点 |
| `workflow` | 较长工作流 | 中轴时间线，4—6 步 |
| `overview:bento` | 首次出现的并列观点 | 主项横向放大，其他信息组成网格，3—5 项 |
| `overview:index` | 第二次出现的并列观点 | 单列编号轨道，适合长名称和解释，3—5 项 |
| `overview:spotlight` | 第三次出现的并列观点 | 左侧核心结论，右侧补充信息栈，3—5 项 |
| `compare` | 前后、传统/新方法、A/B 对比 | 左右分屏，各 2—3 点 |
| `process` | 需要解释的连续步骤 | 折线路径，3—4 步 |
| `case` | 问题—做法—结果 | 三幕式，固定 3 栏 |
| `triangle` | 三要素、支撑关系、闭环 | 中心辐射，固定 3 个节点 |

## 排版规则

1. 先判断页面任务（总览、解释、对比、流程、证据、关系），再选择版式；不能连续三页使用相同视觉轮廓。
2. 主标题超过安全长度时缩放或拆页，不把正文字体缩成小字。
3. 一页只表达一个核心判断；信息过多时增加页面。
4. 小字体只承担解释和补充，不重复主标题。
5. 动画按版式编排：对比页左右进入、流程页沿路径推进、关系页中心向外展开、总览页主项先出现；不再统一使用同一种逐卡动画。
6. 超过版式容量时自动拆成两页；构建阶段会拒绝靠缩小字体硬塞的场景。
7. 视频总时长不设上限；正文按最终旁白动态伸缩。时间公式为：`1.5 秒封面 + 实际旁白 + 0.5 秒正文停顿 + 3.5 秒锁定片尾`。

## 自动选型

先把文章整理为 `content-outline.json`（参考 `content-outline.example.json`），再运行：

```bash
npm run apply:layouts
```

命令会把语义判断真正转换成 `layout-scenes.json` 中的 `type` 和组件字段，并输出
`layout_types`。它会自动拆分超容量段落，并让重复总览按 Bento、Index、Spotlight 三种轮廓轮换；正文达到
5 页时少于 3 种版式会被构建拒绝。制作时仍需检查事实内容和图片素材是否匹配。
